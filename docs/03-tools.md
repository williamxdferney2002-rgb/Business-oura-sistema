# 3 · Tools

## For building (agents)
| Tool | Use in the project |
|---|---|
| **Claude Code** (desktop app and terminal) | Architect: master plan, specifications, audit review, installation guides. Reads `CLAUDE.md`, which imports `AGENTS.md` and sets its role. Uses *skills*, *hooks* (installs test dependencies at session start) and persistent memory of the owner's preferences |
| **Codex CLI** (OpenAI) | Executor and auditor. Reads `AGENTS.md` on its own. Claude launches it with `codex exec` in separate conversations |
| **Skills** (`.claude/skills/<name>/SKILL.md`) | Packaged instructions any model can read by path. 32 installed on day 1, pinned by version in a `skills-lock.json` |
| **Git** | Every stage of every task is a commit (`TASK-XXX: spec | delivery | audit N | close`). It is the evidence of what each auditor reviewed |

| `n8n-workflow-check` | Own | Static review of exported workflows + Code node simulator without n8n |

## For the system
| Tool | Use |
|---|---|
| **Google Sheets** | Database: about 20 tabs generated by a Python script (products, variants, purchases, sales, payments, customers, partners, config, audit…) |
| **Google Apps Script** | Internal app (HTML + `google.script.run`), `api_*` functions also called by the bot, server-side PDF generation with `Utilities`, nightly backup |
| **clasp** + custom sync tool | Code reaches the TEST copy through a command that requires: approved project identity, clean working tree, a closed list of files, typed confirmation "TEST" and verification after pushing. There is no command for the real Sheet: it is updated by hand |
| **n8n** (self-hosted, Docker) | Workflows: bot entry, errors, health (daily reminder). Generated by a Python script and delivered with `active: false` |
| **Google Cloud** e2-micro + **Caddy** | Free server with automatic HTTPS and 2 GB swap so n8n fits in 1 GB of RAM |
| **Telegram Bot API** | Partners' group; Confirm / Cancel / Undo buttons; HTML messages |
| **Gemini** (Google AI Studio, free tier) | Reads Shein order screenshots and payment receipts; interprets free text |
| **Groq** (Whisper) | Transcribes voice notes; numbers spoken as words ("fifty thousand") are converted by code |
| **Gemma** | Fallback when Gemini returns 503 under high demand |
| **Google Drive** | Screenshots of each order ("PED### part N") and receipts |
| **Looker Studio** | Dashboard (pending) |

## For testing outside Google
| Tool | Use |
|---|---|
| **Node.js** + an Apps Script *mock* | Runs the server functions locally; counts Sheet calls as a speed metric |
| **Playwright + Chromium** | Opens the app at 390 px (phone) and 1366 px, tests double tap and font loading |
| **Python** | Static review of n8n workflows (time zone, `parse_mode`, node versions, a single Sheet read) |
| Code node simulator | Runs a node's JavaScript with valid, invalid and duplicate cases without opening n8n |
